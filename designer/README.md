# Lakeflow Designer Files

Create the visual data prep from the Databricks UI inside this folder.

Recommended file name:

```text
renewal_risk_visual_data_prep
```

When committed through a Databricks Git folder, the versioned file appears as:

```text
renewal_risk_visual_data_prep.designer.ipynb
```

That file is the primary visual transformation artifact for this project.

Build the transformation flow on the Lakeflow Designer canvas using Source,
Prepare, Filter, Join, Aggregate, AI Function, and Output operators.
